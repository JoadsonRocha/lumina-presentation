# 📸 Lumina Presentation 2.0 PRO

O **Lumina** é um apresentador e visualizador de **fotos e vídeos** de alta performance, projetado para oferecer uma experiência cinematográfica, imersiva e elegante. Com uma interface baseada em **Glassmorphism de última geração**, ele transforma pastas de mídias em apresentações profissionais com controle de palco e projeção dual-screen.

---

## ✨ Novidades e Funcionalidades Principais

*   🎥 **Suporte Completo a Vídeos & Fotos:** Apresente arquivos de imagem (`JPG, PNG, WEBP, GIF, SVG, AVIF`) e vídeos (`MP4, WEBM, MOV, MKV, AVI`) juntos na mesma apresentação com controles de reprodução nativos e avanço automático de slide após o término do vídeo.
*   📁 **Importação de Pastas Inteiras & Drag & Drop:** Carregue centenas de arquivos ou diretórios completos com varredura automática.
*   📺 **Modo Projeção Sincronizada (Dual Screen):** Controle a apresentação no seu monitor enquanto projeta em tela cheia (1080p / 4K) em outro monitor ou projetor com sincronização em tempo real de filtros, rotação e ajustes.
*   ⏱️ **HUD do Apresentador:** Preview do próximo slide (*Next Up*), cronômetro de palco (*Stopwatch*), e contador em tempo real.
*   🌈 **Efeito Ambilight Dinâmico:** Iluminação halo difusa reativa atrás da imagem baseada nas cores predominantes da foto em exibição.
*   🎬 **Transição Ken Burns & Novas Animações:** Efeito cinematográfico de pan e zoom suave contínuo, além de Crossfade, Zoom-Fade e Slide.
*   🗂️ **Modo Grade / Mosaico (Light Table):** Visão geral em mosaico de todos os slides para navegação ágil, busca por nome, ordenação (A-Z, Tipo, Shuffle) e remoção de itens.
*   🎵 **Playlist de Áudio & Volume:** Reprodutor de múltiplas músicas de fundo com controle de volume deslizante, atalho de mudo e auto-reprodução sequencial.
*   🎭 **Comandos de Palco (Stage Controls):** Tecla `B` para Blackout (tela preta instantânea) e tecla `W` para Whiteout (tela branca).
*   🔄 **Rotação Rápida:** Gire fotos e vídeos em 90°, 180° ou 270° com um clique ou pressionando `R`.
*   💾 **Persistência Total:** Todas as suas preferências e configurações de apresentação são salvas automaticamente.
*   🔔 **Sistema de Toasts Glassmorphism:** Notificações modernas e fluidas integradas ao tema escuro.

## ⌨️ Atalhos de Teclado

| Tecla | Ação |
| :--- | :--- |
| <kbd>→</kbd> ou <kbd>D</kbd> | Próximo Slide |
| <kbd>←</kbd> ou <kbd>A</kbd> | Slide Anterior |
| <kbd>Espaço</kbd> | Iniciar / Pausar Slideshow |
| <kbd>F5</kbd> | Ativar / Desativar Projeção (2ª Tela) |
| <kbd>G</kbd> | Abrir / Fechar Modo Grade (Mosaico) |
| <kbd>B</kbd> | Alternar Modo Blackout (Tela Preta) |
| <kbd>W</kbd> | Alternar Modo Whiteout (Tela Branca) |
| <kbd>R</kbd> | Girar Mídia em 90° |
| <kbd>M</kbd> | Mutar / Desmutar Áudio |
| <kbd>Home</kbd> / <kbd>End</kbd> | Ir para o Primeiro / Último Slide |
| <kbd>F11</kbd> | Alternar Tela Cheia na Janela Principal |
| <kbd>Esc</kbd> | Fechar Modais / Cancelar Overlays |

## 🛠️ Tecnologias Utilizadas

*   **Electron** (Framework Desktop)
*   **JavaScript (ES6+)**
*   **CSS3** (Custom Properties, Glassmorphism, GPU Accelerated Animations)
*   **HTML5 Media Engine** (Video & Audio Players)
*   **Exifr** (Processamento de Metadados EXIF)

## 📦 Como Instalar e Rodar

1. Clone o repositório:
   ```bash
   git clone https://github.com/joadsonrocha/lumina-presentation.git
   ```
2. Instale as dependências:
   ```bash
   npm install
   ```
3. Inicie o aplicativo:
   ```bash
   npm start
   ```
